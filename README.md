# Ufaq Khalid — Portfolio

Live site: [https://my-portfolio-rho-olive-49.vercel.app/](https://my-portfolio-rho-olive-49.vercel.app/)

Code: this GitHub repo. The website is **not** GitHub Pages. Next.js is hosted on Vercel. There is no “main branch site” tab on GitHub. After you push `main`, Vercel rebuilds the live link above.

## Run locally

```bash
npm install
npm run dev
```

Local only: [http://localhost:3000](http://localhost:3000)

```bash
npm run build
npm start
```
